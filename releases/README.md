## 回退

```bash
git checkout v2.5.0
npm ci
npm run build
npm run preview
```

也可以直接解压对应 zip，将其中的 `dist/` 目录静态部署。解压后的 `README.md`
说明了运行、部署与 iPhone 添加到主屏幕的步骤。

## 说明

- 各 zip 是当时构建的完整快照，包含源码、`dist/`、字体、测试报告与截图。
- 2.5.0 起测试为 20 组；包内新增 `src/components/MemoMark.tsx`，备份格式升为 v2。
- 2.0.1 包内包含 `src/lib/archive.ts` 与 `ArchiveTools.tsx`。
- 1.0.3 起字体快照包含 `wufeng-kai.woff2`。
- 版本号同时记录在 `package.json` 与 Git tag 中。
- Service Worker 的缓存名由构建内容哈希生成，切换版本后旧缓存会自动清理。
